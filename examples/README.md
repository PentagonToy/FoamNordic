# Examples

These examples demonstrate supported extension points using only installed FoamNordic interfaces. They are deliberately smaller than the executable research cases under [`tutorials/`](../tutorials/README.md).

| Example | Purpose |
| --- | --- |
| [`externalNutFjord`](openfoam/externalNutFjord/README.md) | Build an incompressible and compressible LES adapter outside the FoamNordic source tree |

Use the [Python API reference](../docs/api/README.md) for solver-independent declarations and the [tutorial index](../tutorials/README.md) for complete case workflows.
